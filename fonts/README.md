# IBM Plex Mono / 可选等宽字体

Unmodified IBM Plex Mono Regular, Italic, Bold and Bold Italic, redistributed under **SIL Open Font License 1.1**, not the repository's MIT license. Copyright and reserved font name notices are preserved in [OFL.txt](OFL.txt).

Source: [IBM/plex](https://github.com/IBM/plex/tree/48e8676114c04f29033b4b53da4ec579f8846297/packages/plex-mono), commit `48e8676114c04f29033b4b53da4ec579f8846297`, `fonts/complete/woff2/` and `LICENSE.txt`.

In Orca Settings → Appearance, choose **IBM Plex Mono** in the terminal or editor font picker. Installation adds a choice; it does not replace your font settings. This Latin/Greek/Cyrillic font has no Chinese glyphs, so Chinese uses the host/system fallback. It is not a Claude proprietary font. The marketing website uses system fonts and does not fetch this family.
