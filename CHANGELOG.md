# Changelog

## 0.2.0

- Redesigned both light and dark palettes with neutral warm surface layers and quieter separators.
- Replaced tan/rust selection fills with warm neutrals; reserved terracotta for actions and focus, with blue links and rose deletion colors.
- Aligned editor, active-tab and terminal backgrounds with the native chat canvas on Orca 1.4.253.
- Revised syntax highlighting, separated punctuation from variables, and added distinct bright ANSI colors.
- Checked primary hover, text, syntax and diff contrast; retained the same 66 supported app tokens and data-only permissions.
- Added design rationale and reference attribution in DESIGN.md.

## 0.1.1

First public release. Packages the existing warm light/dark app and terminal palettes with an MIT license, public installation instructions, and maintenance guidance. Theme colors are unchanged from the local 0.1.0 prototype.
