# 宣传素材与网页维护

`index.html`、`style.css` 与 `app.js` 是零依赖静态展示页。GitHub Pages 从 `main:/docs` 发布；不需要构建、外部字体或分析脚本。

## 素材

所有 `assets/*.png` 为 1600×1000 的静态 PNG，采用真实 Orca 1.4.253 / Claude Paper 0.2.0 界面局部截图。0.2.1 未更改主题颜色。素材包括封面、明暗聊天、明暗 TypeScript 编辑器、浅色 diff、明暗终端，共八张；商店使用封面加六张图库，网页和 README 另展示浅色编辑器。

- `cover.png`：衬线标题与同一聊天的明暗分屏。
- `chat-light.png`、`chat-dark.png`：仅公开演示回复主体。
- `editor-light.png`、`editor-dark.png`：日期格式化 TypeScript 示例。
- `diff-light.png`：日期格式化示例的小幅改动。
- `terminal-light.png`、`terminal-dark.png`：真实 Node 命令输出，以及标明为色样的 ANSI 内容。

截图只做裁切、等比例放大和外部展示框排版，没有替换文字或生成式重绘。聊天中的代码块沿用宿主实际高亮；编辑器截图展示其自身的语法高亮。不同终端图分别采集于示例的小幅改动前后，因此日期格式不同。截图中的字体与字号不由本主题提供。

## 隐私规则

只使用独立公开演示内容。公开图片中不得包含私人聊天、项目列表、用户名、邮箱、设备名、账户、用量、绝对路径或任务标识。原始整窗截图与咨询记录仅留在本地，不能提交到 Git。公开资源必须是裁切排版后的独立 PNG，不能在网页中引用原始截图后仅靠 CSS 隐藏私人区域。

更新素材时逐张查看最终 PNG；仅检查文件名或文本搜索不能替代像素检查。确认图中不含裁切区域以外内容，同时检查 PNG 元数据。不要用临时主题截图的返回标签作为唯一依据：宿主编辑器和终端可能尚未重绘，需肉眼核对实际颜色。

## 检查

在仓库根目录运行：

```sh
node scripts/check-site.mjs
node --check docs/app.js
orca plugin validate . --json
orca plugin check . --json
```

再用浏览器检查 360px 和桌面宽度、两种页面模式、方向键调节对照比例、灯箱的 Escape 关闭与焦点返回、复制成功/失败提示、减少动态效果，以及禁用 JavaScript 后的图片和安装说明。

图片尺寸与限额：封面至少 800×500、≤1 MiB；商店截图最多六张、每张至少 1280×800 且 ≤1.5 MiB、合计 ≤8 MiB。当前全部按 1600×1000 导出。

网站的 CSS 配色与主题令牌对应；修改主题后同步调色板及截图。网页动效仅为轻微 hover 过渡，尊重系统减少动态效果设置，不属于主题插件功能。
