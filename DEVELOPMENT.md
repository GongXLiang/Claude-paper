# Development / 维护说明

This repository root is the data-only Orca plugin. Keep app and terminal palettes native; do not patch Orca resources or add unsupported tokens.

## Sources

- `scripts/build-icons.py` generates the active SVGs in `icons/files/`, three defaults, `icons/theme.json`, `icons/catalogue.json` and `icons/COVERAGE.md`. There are 340 suffixes + 115 exact filenames + 3 defaults = **458 mappings**, below Orca's 512 limit. Every active file mapping owns a distinct SVG. Closed/open folders are uniform slate; folder-name maps must stay empty. `icons/folders.json` and old root SVGs are historical, unused by the generator.
- `scripts/site-template.html` and `scripts/site-copy.json` are the bilingual page sources. `scripts/build-site.py` generates both HTML pages; edit those sources rather than generated HTML.
- `docs/style.css` / `docs/app.js` implement paper presentation and decode-gated scene switching. GSAP/ScrollTrigger 3.15.1 are pinned local website dependencies, with their own license in `docs/vendor/NOTICE.txt`; no runtime code or capability is added to the Orca plugin.
- `scripts/build-gallery.py` generates bilingual SVG specimen sheets. Render them into `docs/assets/icons{,-zh}.png`. The website specimens are inline SVG at real 16/20 px sizes.
- `scripts/media-cover.html` renders the cover using one complete native image. Capture inputs and export requirements are in [MEDIA.md](docs/MEDIA.md).
- Optional Codex syntax themes are generated by `scripts/build-codex.py`; the explicit installer never changes Codex configuration. IBM Plex Mono faces retain their OFL license and hashes.

## Checks

```sh
python scripts/build-icons.py
python scripts/build-gallery.py
python scripts/build-site.py
python scripts/check-theme.py
python scripts/check-extras.py
node scripts/check-site.mjs
node --check docs/app.js
node --test examples/date-kit/format.test.mjs
orca plugin validate . --json
orca plugin check . --json
```

Evaluate `scripts/check-browser.js` in a real browser on both language pages; evaluate `scripts/check-motion.js` in a normal-motion desktop browser. Also verify native captures, 360 px layout, no-JS, reduced motion, actual keyboard input, image-load failure, slow decode, manual scene selection during pinned scroll, and lightbox zoom. Observe icon recognizability at 16/20 px; geometry uniqueness is not proof of perceptual distinction.

## Install and release

Directory installation is a snapshot; reinstall the folder after an edit. Git installation derives the publisher from the repository owner; local installation uses `local`. Do not add a legacy publisher field.

```sh
orca plugin install . --json
```

Bump the manifest version and changelog, pass the checks and publish a **new** `vX.Y.Z` tag. Never move an existing release tag. The repository retains the `orca-plugin` topic; the community index scans tags asynchronously. Check the [store status](https://www.onorca.dev/plugins/gongxliang/claude-paper) separately from the GitHub release.

GitHub Pages serves `main:/docs`. `.github/workflows/install-stats.yml` refreshes official installation totals twice daily and explicitly requests a Pages build after its own commit. `scripts/refresh-stats.py` rejects invalid or older snapshots and retains the last valid dated count on network failure. Regenerate the pages after refreshing the snapshot.

Only public, privacy-reviewed assets enter Git. No personal captures, account details, credentials or private paths. Public fixture paths such as `D:/paper-demo/date-kit` are intentional. No third-party screenshots or SVGs are copied.
