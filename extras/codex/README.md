# Claude Paper for Codex CLI

[English](README.md) · [简体中文](README.zh-CN.md)

Two optional syntax themes share Claude Paper’s editor palette. They color fenced code and file diffs in Codex CLI. The terminal still controls its base palette; the CLI controls its layout, message styling and any hardcoded truecolor.

## Install

From a downloaded or cloned **Claude Paper repository**:

```sh
node scripts/install-codex.mjs --dry-run
node scripts/install-codex.mjs
```

The installer copies only `claude-paper-light.tmTheme` and `claude-paper-dark.tmTheme` into `$CODEX_HOME/themes`, or `~/.codex/themes` when `CODEX_HOME` is unset. It never edits `config.toml` and refuses to overwrite different files. `--destination /your/path` chooses an explicit theme folder. No dependencies are installed.

In Codex CLI, run `/theme`, search **claude-paper**, and select the light or dark entry to match the terminal. Codex saves that selection itself. The syntax theme does **not** switch automatically when Orca changes mode. If a running CLI retains old message backgrounds after a mode change, restart/resume that CLI to let it detect the new terminal background.

Installing the Orca plugin alone does not install these companion files. They were verified in Codex CLI 0.167.0 on Windows with Orca 1.4.255.

## Remove

Choose another theme with `/theme`, then remove only the two companion files you installed. Keep any unrelated themes.

Generated by `python scripts/build-codex.py` from `themes/light.json` and `themes/dark.json`. [Official Codex customization guide](https://learn.chatgpt.com/docs/cli-customization).
